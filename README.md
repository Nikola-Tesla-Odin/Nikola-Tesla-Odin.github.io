# Token Voices studio

https://nikola-tesla-odin.github.io/

A static site where an Odin.fun token's creator signs in with
[Odin Connect](https://github.com/Toniq-Labs/odin-connect), picks or creates a voice (Claude, with their own
key, called from their browser), previews a post, and gets their own copy of
[token-voice-bot](https://github.com/Nikola-Tesla-Odin/token-voice-bot) running on GitHub Actions.

There is no server: keys never leave the visitor's browser and their own GitHub account.

```bash
npm install && npm run dev
```
